# IsKeyBindRegistered

`IsKeyBindRegistered` 用于检查在调用时刻，所给的按键是否已被注册。

## 参数（重载 #1）

| # | 类型 | 子类型 | 说明 |
|---|------|--------|------|
| 1 | integer | Key | 要检查的按键 |

## 参数（重载 #2）

| # | 类型 | 子类型 | 说明 |
|---|------|--------|------|
| 1 | integer | Key | 要绑定的按键，请使用 `Key` 表 |
| 2 | table | ModifierKeys | 与 `Key` 参数一起检查的修饰键 |
