# C++ 示例

用于制作 UE4SS C++ mod 的模板仓库：[UE4SSCPPTemplate](https://github.com/UE4SS-RE/UE4SSCPPTemplate)。请注意，如果你基于最新的 main 分支进行开发，而模板中又有尚未合并到 `main` 的改动时，你应该使用该模板仓库的 `dev` 分支。

在 GitHub 上搜索任意调用了命名足够独特的 UE4SS API 函数的 Lua 代码，搜索时排除 UE4SS 仓库本身：

https://github.com/search?q=language%3Acpp++%22+%3A+public+CppUserModBase%22+NOT+repo%3AUE4SS-RE%2FRE-UE4SS+NOT+repo%3AEpicGames%2FUnrealEngine&type=code
